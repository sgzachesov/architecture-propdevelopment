# Требования к внешним интеграциям — сервисы «Умный дом»

Партнёр предоставляет два сервиса, доступных через приложение собственников:
**интеллектуальный домофон** (звонок + биометрия по лицу) и **интеллектуальный шлагбаум** (распознавание номеров).
PropDevelopment — продукт и бизнес-логика доступа, партнёр — оборудование, биометрия и медиапотоки.

## 1. Требования к безопасности

- Все вызовы — только по **TLS 1.2+**.
- M2M-интеграция: **OAuth 2.0 client_credentials**; у каждого партнёра — свои учётные данные (никаких общих ключей между УК).
- **Минимум данных:** биометрия (лица) и госномера **не передаются и не хранятся в PropDevelopment** — они остаются у партнёра. В событиях только обезличенные идентификаторы (Event-Id, id устройства, id объекта).
- **Изоляция по объектам:** собственник и устройство имеют доступ только к своему объекту; проверка права доступа — в момент запроса; отзыв доступа применяется партнёром.
- **Целостность и журнал:** события подписаны (JWS/HMAC) и идемпотентны (уникальный Event-Id); доставка событий без потерь.

## 2. Протоколы аутентификации и авторизации

| Направление | Протокол |
|---|---|
| Собственник → PropDevelopment (приложение) | OAuth 2.0 / OIDC, `authorization_code` + PKCE (Keycloak) |
| PropDevelopment ↔ Партнёр (M2M) | OAuth 2.0 `client_credentials` |
| Партнёр → PropDevelopment (события) | Подписанные webhook (JWS/HMAC), идемпотентность по Event-Id |


## 3. Организация взаимодействия

```
Приложение собственников → smart-home-integration-app (PropDevelopment) → Платформа «Умный дом» (партнёр) → оборудование
```

- **Синхронно (REST):** проверка права доступа при попытке прохода; действия собственника (открыть дверь/шлагбаум, статусы, журнал).
- **Асинхронно (webhook/очередь):** от партнёра — звонок, попытка доступа, статусы устройств; от PropDevelopment — изменения прав доступа и конфигурация объекта. Ретраи, идемпотентность, подтверждения.
- **Медиа (видеозвонок):** через партнёрскую платформу; PropDevelopment даёт только identity и права на звонок.
- **Контракты:** OpenAPI, версионирование, песочница партнёра.
